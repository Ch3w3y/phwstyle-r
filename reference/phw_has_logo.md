# Does phwstyle have a PHW logo to use?

Every output can use a PNG logo, so this is `TRUE` when the white logo
is available as a PNG. HTML outputs use the SVG instead when there is
one.

## Usage

``` r
phw_has_logo()
```

## Value

`TRUE` or `FALSE`.

## Examples

``` r
phw_has_logo()
#> [1] FALSE
```
