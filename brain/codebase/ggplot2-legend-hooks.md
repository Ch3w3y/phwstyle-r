# Choosing a legend for every chart

- **A theme can't choose a legend.** No theme element sets `nrow` or the guide class, and ggplot2 4.0 resolves each scale's guide (`Guides$setup()`) before any palette runs, so a theme palette that receives the scale as `self` is too late to change `self$guide`.
- **The `ggplot2.discrete.*` options clash with theme palettes on 4.0.** `theme()` warns "options(...) setting is incompatible with the palette theme setting" whenever a discrete palette element is set while the option is set, so `use_phw_ggplot()` sets those options only before 4.0. Every later `theme_phw()` would warn.
- So `wrap_legends()` swaps in `phw_guide_legend()` where phwstyle draws a chart: `phw_save()`, `phw_finalise()`, `phw_arrange()`, `phw_add_slide()`, and knitr's `render` chunk option in the `phw_*_document()` formats. Plain `print()`, `ggsave()` and Quarto don't go through it.
- A guide's `draw()` runs while the target device is open, so `grid::unit(1, "npc")` there is the width the chart is drawn at. `phw_finalise()` builds its gtable before that size is known, so `makeContext.phw_finalised()` builds it again when drawn.
- knitr's default `render` adds the class `knit_asis_htmlwidget` to htmlwidget output (for figure captions); a custom `render` has to do the same.
- patchwork places a collected bottom or top legend from the left of the first panel to the right of the last (`attach_guides()`), so it starts after the y axis, and it ignores `legend.location`. With `legend.location = "plot"` (as in `theme_phw()`), `phw_guide_legend()` wraps to the figure's width (patchwork's title columns, 3 to n - 2) and moves each legend left to the title's edge, inside a wrapper of the same size, because ggplot2's `package_box()` overwrites each legend's own viewport. Wrapping to the panel span alone wrapped two legends of full health-board names to 6 + 1 rows and squashed the panels (#408); the room beside the y axis depends on the y labels, so a fix that only widened the room to the right margin held for two-digit counts and failed for counts in the hundreds. A test of a collected legend must check where it starts and ends, not only its width (#391). In `collected_room()`, measure the fixed columns and take the panels' width as the rest: `convertWidth()` of a `null` panel width is not its drawn width. Test data needs varying values: a constant `cases = 20` gives y labels like "19.975", which widen the axis.
- Measure legend widths on `ragg::agg_png()`, as `phw_save()` draws. Base `png()` has no PHW font, so its text is narrower and a legend that runs off looks as if it fits.
